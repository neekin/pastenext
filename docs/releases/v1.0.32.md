PasteNext v1.0.32 补齐 Windows 桌面贴图的隐藏、恢复和管理入口。

- **右键隐藏贴图**：Windows 图片贴图现在使用完整的贴图窗口，右键可选择「隐藏贴图」或「关闭贴图」，也可按 `Esc` 隐藏。
- **面板一键恢复**：有隐藏贴图时，剪贴板面板顶部显示「恢复贴图（数量）」；「贴图」面板还可逐张恢复、关闭或批量隐藏和恢复。
- **托盘管理**：Windows 托盘新增「桌面贴图」分组，提供恢复全部、隐藏全部和解除鼠标穿透，菜单随操作立即更新。
- **持久化与统一入口**：剪贴板历史和截图工作台创建的 Windows 贴图共用管理状态。贴图拥有独立图片副本，保存位置、缩放、透明度和隐藏状态，重启后可恢复；关闭才会移除保存的贴图。
- **Windows 窗口操作**：支持等比缩放、工作区内定位、上下层级和鼠标穿透；恢复隐藏贴图不会修改其他可见贴图的穿透设置。

已通过前端构建和测试、Rust 单元测试，以及 Windows / macOS 原生三进程验证，覆盖贴图隐藏、真实面板恢复按钮、重启恢复及关闭后移除保存的贴图。Windows 安装后的客户端检查也已通过。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。

PasteNext v1.0.32 adds persistent desktop pin management on Windows. Right-click a pin to hide or close it, or press Escape to hide. Hidden pins can be restored from the clipboard panel's Restore pins button or the new Desktop pins tray menu. The panel also supports individual and batch recovery.

Clipboard image pins and Capture Studio pins now share the same management and persistence. Independent image snapshots, position, zoom, opacity and hidden state survive restarts. Windows pins also support proportional resizing, adjacent layer ordering and click-through; restoring hidden pins preserves click-through on other visible pins.

Validated with frontend builds and tests, Rust tests, and native Windows/macOS tests spanning three separate application processes. Coverage includes hiding, recovery through the real panel button, restart persistence, and removal after closing. Installed Windows client checks also passed.
