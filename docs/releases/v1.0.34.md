PasteNext v1.0.34 修复关闭「截图后立即编辑」后的截图行为。

- **自动复制截图**：截图完成后自动写入系统剪贴板，可直接粘贴到其他应用。
- **后台截图安静结束**：关闭立即编辑时，后台截图完成后不再自动打开工作台，前端也不再切换到媒体历史。
- **保留历史记录**：截图继续保存在历史记录中；原本已打开的工作台会回到当前页面，便于继续截图或添加长截图画面。
- **按需打开编辑器**：开启立即编辑或完成录屏时，继续打开编辑器；取消截图时仍按原有窗口状态恢复。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。

PasteNext v1.0.34 fixes screenshot behavior when Edit after capture is disabled.

- Completed screenshots are automatically copied to the system clipboard for immediate pasting.
- Background captures finish without opening Capture Studio or switching to Library.
- Screenshots remain in history. If Capture Studio was already open, it returns to the current page so capture and long-screenshot workflows can continue.
- Immediate editing and completed recordings still open the editor. Cancelled captures retain the existing window restoration behavior.

Includes macOS Apple Silicon / Intel DMGs, Windows x64 EXE / MSI / portable ZIP, and SHA256SUMS.
