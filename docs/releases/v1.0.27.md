PasteNext v1.0.27 将截图、录屏和局域网传图加入正式客户端，支持 macOS 与 Windows。

- 截图：区域、窗口、全屏；选区外暗化 60%，可直接通过浮动栏或 1 / 2 / 3 切换模式，支持移动和调整选区。
- 编辑：箭头、矩形、文字、裁剪、马赛克、模糊、撤销重做，支持离线 OCR、贴图和截图历史。
- 录屏：快捷键开始与停止，保存后可播放，并导出 MP4、MOV 或 GIF。
- 长截图：手动滚动添加画面，再自动识别重叠部分拼接。
- 扫码传图：电脑和手机在同一局域网内互传图片，下载与上传通过限时会话完成，无需云中转。
- 交互优化：面板唤醒、条目选择、双击粘贴和内容填充流程。
- macOS 使用同一固定签名证书构建，保持后续版本的代码身份一致。

默认快捷键：macOS 为 **Command + Shift + A / R / G**，Windows 为 **Ctrl + Shift + A / R / G**，分别对应截图、录屏启停、长截图工作台。

安装包：macOS Apple Silicon / Intel DMG，Windows x64 EXE / MSI / 便携 ZIP。便携版数据保存在程序同目录的 `Data/` 中。

当前录屏不含声音；GIF 最长 120 秒；长截图需要手动滚动并添加画面。macOS 固定签名是自签名证书，尚未获得 Apple Developer ID 公证，首次安装仍可能需要在系统设置中允许打开。

---

Screenshots, annotations, offline OCR, pinned images, long-image stitching, recording, video/GIF export and local phone image transfers are now included on macOS and Windows. Use the floating capture toolbar or 1 / 2 / 3 to switch between region, window and display modes.

Shortcuts: **Command + Shift + A / R / G** on macOS; **Ctrl + Shift + A / R / G** on Windows. Recordings currently have no audio. Long capture requires manually scrolling and adding frames. macOS builds reuse one persistent self-signed certificate and are not Apple-notarized.
