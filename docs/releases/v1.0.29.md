PasteNext v1.0.29 改进 macOS 桌面贴图，并加入可选择系统或内置的桌面便签。

- **持久化桌面贴图（macOS）**：图片历史和截图工作台使用同一套贴图窗口，保存位置、缩放、透明度与隐藏状态；清理原历史后仍可恢复贴图。
- **简洁的贴图操作（macOS）**：图片下方不再显示工具栏；右键操作集中到原生菜单。拖拽右下角可等比缩放，也支持滚轮、触控板捏合及系统三指拖移。
- **贴图重新编辑（macOS）**：右键「编辑图片…」暂时隐藏原贴图，在截图工作台继续裁剪和标注。点击「使用图片」替换并显示原贴图，取消编辑或关闭工作台则恢复原图。数字标注统一在工作台使用，旧贴图标记仍可继续编辑。
- **连续透明度与层级（macOS）**：透明度支持滑块及百分比输入；多张图片重叠时可右键「向上一层」「向下一层」，逐层调整并保持置顶。
- **历史记录转桌面内容**：图片卡片可直接「贴到桌面」；文字卡片可「发送到便签」。Windows 图片沿用截图工作台的贴图窗口。
- **便签方式可选**：设置中选择「使用系统便签」或「使用内置便签」。macOS 调用系统便笺；Windows 打开 Sticky Notes 并复制文字供粘贴。系统便签不可用时自动使用内置便签。
- **内置便签**：内容在本机自动保存，退出后重启恢复；关闭窗口会保留内容，可从托盘重新显示，清理剪贴板历史不影响便签。
- **托盘菜单整理**：截图与录屏、桌面贴图、便签分别分组，权限和授权入口仅在需要处理时显示。

本机验证包括前端构建与测试、44 项 Rust 测试、macOS 三进程原生窗口测试及 Windows 代码交叉编译检查。macOS 窗口测试覆盖贴图逐层移动、角落缩放、透明度输入、编辑回填与取消、保存和重启恢复。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。正式安装包由 GitHub Actions 使用仓库配置的许可密钥构建；macOS 继续复用现有固定签名证书。

macOS desktop pins now persist independently of clipboard history, with native context menus, proportional corner resizing, continuous opacity controls, and adjacent layer ordering. Send a pin back to the capture studio to crop or annotate it; applying replaces the same pin, while canceling restores the original.

Text history can be sent to system or built-in sticky notes. macOS uses Stickies; Windows opens Sticky Notes with the text copied for pasting. If system notes are unavailable, PasteNext creates a built-in note with local autosaving and restart recovery. Image history can be pinned on both platforms, with Windows retaining its existing capture-studio pin window.
