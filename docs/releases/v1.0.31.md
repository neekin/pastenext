PasteNext v1.0.31 修复 Windows 使用普通鼠标滚轮时，剪贴板历史记录无法滚动的问题。

- **滚轮浏览历史**：在历史卡片区域向下滚动可查看后面的记录，向上滚动可返回前面的记录。
- **保留横向操作**：触控板横向手势与 Shift 滚轮继续使用浏览器原有的横向滚动；Ctrl 滚轮不触发历史列表滚动。
- **兼容不同滚轮输入**：支持按像素、行、页上报的滚动距离，滚动时同步更新虚拟列表中的卡片。

已通过前端构建、现有测试与 Chromium 浏览器滚轮回归验证。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。正式包由 GitHub Actions 构建，macOS 继续复用现有固定签名证书。

PasteNext v1.0.31 fixes mouse-wheel scrolling in the clipboard history on Windows. Vertical wheel input now scrolls the horizontal card list, with support for pixel, line and page deltas. Native horizontal gestures, Shift scrolling and Ctrl wheel behavior are preserved, and virtualized cards update while scrolling.

Validated with the frontend build, existing tests and Chromium browser wheel regression checks.
