PasteNext v1.0.28 优化截图唤醒速度，并统一 Windows 默认快捷键。

- **Windows 默认快捷键**：截图 `Ctrl+Alt+A`、录屏启停 `Ctrl+Alt+R`、长截图工作台 `Ctrl+Alt+G`；剪贴板面板继续使用 `Ctrl+Alt+V`。macOS 保持 `Command+Shift+A / R / G`。
- **升级迁移**：自动迁移旧截图默认组合；其他自定义组合保留，迁移后手动选择的组合也不会在重启时被覆盖。
- **更快打开截图**：提前初始化一个空闲原生选区进程，按下快捷键后直接唤醒；实际屏幕内容仍在用户发起截图时读取。取消或完成后会准备下一次截图。
- **减少等待和重绘**：移除固定 140 毫秒等待，按窗口状态等待必要的画面更新；区域和全屏模式跳过窗口列表扫描，减少鼠标移动时的重复绘制。
- **固定签名**：macOS 继续复用 v1.0.27 的同一签名证书；GitHub Actions 会校验 DMG 内的应用版本、架构和签名。

原生验证包括 macOS 28 项、Windows 30 项 Rust 测试，以及安装后的快捷键、截图、录屏启停、视频播放、OCR 与局域网传图测试。启动耗时的具体测量方式和结果见仓库 `docs/screenshot/validation.json`，实际速度取决于设备和运行状态。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。

---

Windows defaults now use **Ctrl+Alt+A / R / G** for screenshots, recording start/stop and long capture; the panel remains **Ctrl+Alt+V**. macOS keeps **Command+Shift+A / R / G**. Old capture defaults migrate once while custom bindings are preserved.

An idle native selector is initialized before capture, removing repeated startup work. The unconditional 140 ms delay is gone, region/display capture skips window enumeration, and idle pointer movement avoids redundant redraws. macOS releases retain the existing signing identity.
