PasteNext v1.0.30 修复 macOS 隐藏贴图后恢复入口不明显、托盘菜单状态刷新延迟的问题。

- **一键恢复隐藏贴图**：有隐藏图片时，剪贴板面板顶部直接显示「恢复贴图（数量）」，点击即可找回原贴图；也可进入「贴图」逐张恢复。
- **托盘立即更新**：创建、隐藏、恢复和关闭贴图后，菜单立即刷新，不再依赖下一次点击托盘才更新。修复首次贴图隐藏后，恢复菜单可能仍显示为灰色的问题。
- **显示隐藏数量**：托盘「桌面贴图」显示已隐藏的图片数量，便于发现仍保存着的贴图。
- **保留其他贴图状态**：一键恢复只处理隐藏的贴图，其他可见贴图的鼠标穿透设置保持不变。
- **面板状态更可靠**：面板重新获得焦点或操作完成后主动同步贴图列表，操作失败时显示错误提示。

隐藏会保留图片和显示设置；关闭才会移除贴图。本次更新保留 v1.0.29 的截图、贴图编辑和便签功能。

已通过前端构建与测试、44 项 Rust 测试及 macOS 原生三进程窗口测试。原生测试覆盖首次创建和隐藏后菜单立即可用、点击面板恢复按钮找回原窗口，以及恢复时保留其他贴图的鼠标穿透设置。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。正式包继续由 GitHub Actions 构建，macOS 复用现有固定签名证书。

macOS hidden pins now have a prominent Restore pins button in the clipboard panel. Tray menu availability updates immediately when pins are created, hidden, restored or closed, and the menu shows the hidden count. Restoring hidden pins preserves click-through settings on other visible pins. Hiding keeps the saved image; closing removes it.

Validated with the frontend build and tests, 44 Rust tests, and native macOS window tests covering immediate menu updates, recovery through the real panel button, and preservation of other pins' mouse interaction settings.
