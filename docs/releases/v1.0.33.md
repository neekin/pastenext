PasteNext v1.0.33 修复 Windows v1.0.32 双击后无反应、快捷键无法唤起的问题。

- **修复启动崩溃**：WebView2 在构建初始窗口时可能提前请求贴图列表，而后台尚未完成贴图状态注册。v1.0.32 会因此直接终止进程。现在初始化完成前的查询安全返回，之后由正常刷新取得贴图状态。
- **保留便携数据**：升级时保留原 `Data` 文件夹，已有剪贴板历史、设置和保存的贴图继续使用。
- **验证最终安装包**：Windows CI 在打包之后实际安装并启动生成的 EXE，并检查便携目录的冷启动、保留数据重启和面板唤起。检查通过后才上传发布产物。
- **保留贴图管理**：继续支持 Windows 贴图右键隐藏、面板一键恢复、托盘批量隐藏和恢复，以及贴图持久化。

本次问题已通过下载并启动 v1.0.32 正式便携包复现；全新解压和保留原 Data 目录升级均捕获到贴图状态注册前访问导致的崩溃。

提供 macOS Apple Silicon / Intel DMG、Windows x64 EXE / MSI / 便携 ZIP，以及 `SHA256SUMS` 校验文件。

PasteNext v1.0.33 fixes a Windows startup crash in v1.0.32. WebView2 could request the pin list while initial windows were still being constructed, before the persistent pin state had been registered. Early reads now return safely, and normal refreshes load the saved state after initialization.

Portable upgrades retain the existing Data directory, clipboard history, settings and saved pins. Windows CI now installs and launches the actual packaged EXE and checks portable cold startup, restart with retained data, and panel activation before uploading release artifacts.

The original crash was reproduced using the downloaded v1.0.32 production portable ZIP in both clean and upgrade directories. Windows pin hiding, recovery, tray management and persistence remain available.
