# 截图、录屏与扫码传图

本次实现覆盖 macOS 与 Windows 原生客户端，参考用户提供的腾讯「截图.app」2.3.0。
参考证据见 `jietu-reference.json`。没有复用其二进制、框架、贴纸或服务端接口。

## 已实现

- 区域、窗口、全屏截图；显示器选择、倒计时、取消及系统权限提示。
- Retina / 普通分辨率、截图声音、PNG / JPEG 质量、自动保存文件夹、截图后编辑偏好。
- 裁剪、矩形、椭圆、线段、箭头、画笔、荧光笔、文字、序号、马赛克、模糊和 emoji 贴纸。
- 撤销 / 重做、缩放、编辑草稿在窗口内切换媒体时保留。拖动时缓存已完成的标注，避免重复计算像素模糊。
- 剪贴板、图片保存、OCR、图片贴图、已有图片编辑、剪贴板历史与独立媒体列表。
- 长截图：手动滚动后分帧截取或导入，自动检测纵向重叠、拒绝重复画面；匹配不确定时由用户调整接缝，确认后生成可继续编辑的长图。
- 区域 / 全屏录屏、倒计时、点击提示、状态 / 计时、结束保存及放弃；原生 MP4 / MOV / GIF 转换，支持高清或较小文件。
- 同一局域网的双向传图：二维码下载当前图片 / 视频，手机上传图片进入历史。十分钟有效期、停止撤销、可切换网卡、40 MB 上传上限、随机会话 token、来源 / Host 验证。
- 面板、菜单栏和设置入口，快捷键可自定义；关闭工作台停止分享，退出应用终止捕获进程。

## 默认快捷键（按用户要求随平台适配）

| 功能 | 默认组合 |
| --- | --- |
| 截图 | macOS Command / Windows Ctrl + Shift + A |
| 开始 / 结束录屏 | macOS Command / Windows Ctrl + Shift + R |
| 打开长截图 | macOS Command / Windows Ctrl + Shift + G |
| 打开图片 | Command + O |
| 保存 / 另存 | Command + S / Shift + Command + S |
| 撤销 / 重做 | Command + Z / Shift + Command + Z |
| 复制图片 | Command + C |
| 缩放 | Command + 加号 / 减号 |
| 关闭工作台 | Command + W |

保留用户自定义组合，仅迁移本次开发中使用过的临时默认组合。
快捷键注册失败会保留原设置；截图时可用浮动栏或 1 / 2 / 3 切换区域、窗口、全屏，无需打开工作台；选区外遮罩强度为 60%。

## 已完成验证

详见 `validation.json`，数据均来自生成的测试素材及隔离的 `io.pastenext.preview` 原生客户端。

- 前端构建、既有授权 / 面板测试、新增裁剪几何、撤销重做不可变性及模糊像素测试通过。
- macOS Rust 27 项测试通过，包括数据库迁移、图片归一化、请求长度校验及长图拼接（含奇数像素偏移、空白歧义及尺寸错误）。
- 实际 WKWebView + Rust IPC：640×400 图片加载 / 标注 / 裁剪得到 590×360；OCR 识别测试文字；图片成功进入系统剪贴板，测试后恢复原剪贴板。
- 原生屏幕录制权限生效；全屏截图得到 5120×2880，普通模式得到 2560×1440；自动保存 JPEG 文件头正确。
- 真实屏幕录制、通过生产 IPC 结束保存；原生视频播放器就绪，播放 4096×2304 录屏。放弃截图不产生新媒体，状态恢复空闲。
- Swift 导出引擎生成有效 MP4 / MOV / GIF，视频时长 / 视频轨道 / GIF 帧数均检查过；不依赖外部 FFmpeg。
- 原生拼接 IPC：两帧各 120×300、重叠 120 像素，得到 120×480；单元测试逐像素比对合并结果。
- 实际客户端提供的 HTTP 服务完成下载逐字节比对、图片上传 / 入库、非法来源 / 无效图片 / 过大请求拒绝以及停止后连接失效。
- macOS 客户端窗口已截取并检查实际渲染，视频页面无水平溢出。REA 的 AX 观察因宿主未获辅助功能权限而不可用，没有将静态分析冒充原生操作验证。
- 使用既有固定本地证书签名；重建预览客户端后原有屏幕录制授权仍有效。

## 明确边界

- 长截图需要用户滚动并添加下一帧，不是自动滚动抓取；固定页眉应排除在选区外。最多 12 帧、总计 6400 万像素，输出高度最多 32767 像素。
- GIF 导出最长 120 秒，默认 10 FPS、最大边 960 或 640 像素。当前录屏不提供音轨录制选项。
- 图片传输支持 PNG、JPEG、GIF、BMP、TIFF，按静态图片归一化；不包含 HEIC、远程云中转、跨公网或手机视频上传。
- 手机尺寸浏览器验证被工具以 `ERR_BLOCKED_BY_CLIENT` 拦截；协议与原生端通过测试，真实手机和不同 Wi-Fi / 防火墙环境尚未验证。临时测试工作区已按用户要求关闭。
- Windows 使用原生 Win32 选区及随包分发的 FFmpeg LGPL 引擎，已通过 Windows 构建与媒体功能测试；详见 `platform-parity.md`。Linux 引擎尚未接入。
- 此次是固定本地签名的预览客户端，未替换正式版，未发布远程版本。自签名不是 Apple Developer ID 或公证。
